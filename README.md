# AnimeVerse Android APK wrapper

This project wraps the live AnimeVerse PWA in a lightweight Android WebView.

Live site: https://animeverse-2i2n.onrender.com

## Build on GitHub from a phone
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open Actions and run **Build AnimeVerse APK**.
4. Open the completed workflow run and download the **AnimeVerse-APK** artifact.
5. Extract the ZIP and install `app-debug.apk` on Android.

This wrapper only loads the user's live site. It does not add or provide unauthorized anime sources.
